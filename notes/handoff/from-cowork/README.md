# Messages in, from the Cowork session

One file per hand-off, `YYYY-MM-DD-slug.md`. See `../README.md` for the convention.

Empty as of 2026-09-27: everything received up to and including that day's twelve-entry baton
is in `../archive/from-cowork-through-2026-09-27.md`, kept whole.

**The Cowork session does not run git.** A hand-off arrives as a file left in this directory;
committing it happens here. If a hand-off asks for a change to the repository, the request
lives in the file and the change is made as a separate, reviewable commit — never inside the
hand-off itself.
