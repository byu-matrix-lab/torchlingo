# Lecture 16 Assignment - create & run SLT pipeline

*Transcribed from the Learning Suite assignment description on 2026-09-29. Learning Suite due date: Wed Nov 4, 10:00. Points: 20. Roadmap v6 due date: Mon Nov 9. Status: current in substance; due date not yet moved. Rubric tables reformatted; otherwise verbatim.*

1. Get a free Azure account - you'll need a subscription and translator/speech resource keys to access services - go to: https://azure.microsoft.com/en-us/pricing/purchase-options/azure-account?icid=azurefreeaccount
2. Create your own simple speech-to-speech pipeline for your language (or another) using the standard Microsoft components (ASR, MT, TTS).
3. Refer to the Microsoft documentation as needed for ASR, MT, and TTS. Be sure to use the Python example code.
4. Make the code consistent across components. Include all functions in a single file. Document it well!
5. NOTE: Do NOT use the Microsoft Speech Translation API! (A single API that does everything). You must put together the 3 separate components yourself!
6. Select 10 sentences from your cleaned data (at least 10 words each)
7. Speak them into your pipeline (one at a time is ok), recording your speech and the resulting spoken output.
8. For one sentence, record a video of you speaking the source text and your system generating the spoken target translation.

Upload the following files into the subfolder with your last name in the shared folder:
- Your well-documented code with instructions to run it. Test it! If we can’t run it, you will lose points!
- The source text of the 10 sentences you selected and the target text generated by MT
- Audio recordings of your 10 spoken sentences and the corresponding spoken target translations
- Video recording of you speaking one sentence and your STS pipeline speaking the target translation

You need to upload all these files to get full credit for the assignment!
